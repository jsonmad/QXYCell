The core staged workflow

Build the analysis one checkpoint at a time. Every successful stage refreshes the active H5AD, cells_obs.csv, and markers_var.csv.

  1. Measurements: create the base AnnData.
  2. Annotations: add or replace GeoJSON-derived data.
  3. Thresholds: explicitly choose classifier JSON or one threshold table.
  4. Prompt: generate the LLM prompt used to draft the YAML.
  5. Cell types: apply the reviewed YAML.
import qxycell as qxy

adata = qxy.import_measurements("/path/to/qupath_project")
qxy.add_annotations(adata, pixel_size_um=0.28)

# Choose exactly one threshold source:
qxy.threshold_from_classifiers(adata)
# qxy.threshold_from_table(adata, "thresholds.tsv")

qxy.celltype_prompt(adata, context="Describe the tissue and expected populations")
qxy.celltype(adata)

Designed for iteration: after stage 1, rerun any changed stage. New GeoJSON, thresholds, prompts, or YAML replace that stage’s prior outputs and invalidate dependent downstream results.

The interactive notebook and numbered Python scripts implement the same staged workflow. Use the notebook cell by cell or run the scripts from a terminal.

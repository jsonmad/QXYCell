QuXYCell Function and Command Reference

Notebook and CLI reference for QuPath export to AnnData workflows.

Standard import: import quxycell as qxy

Core QuXYCell Functions

Function Purpose Typical command Key output
qxy.check Inspect and validate a manually exported QuPath project. report = qxy.check(qupath_project) CheckReport plus check report files in qxy_outputs_YYMMDD-HHMM/.
qxy.run Import QuPath measurements, classifier thresholds, spatial coordinates, and GeoJSON annotations into AnnData. adata = qxy.run(qupath_project) AnnData plus saved H5AD and tables.
qxy.celltype_prompt Create a copy-paste LLM prompt from markers found in the AnnData object. prompt = qxy.celltype_prompt(adata) Prompt text and a saved prompt file in the run celltype/ folder.
qxy.celltype Apply ordered first-match cell type YAML logic. summary = qxy.celltype(adata) Adds adata.obs["celltype"] and saves a rule summary TSV.
qxy.remove_ignore Remove cells inside annotation columns containing Ignore. qxy.remove_ignore(adata) Filters adata in place by default.
qxy.assign_samples Assign one sample label per cell from annotation columns containing sample. sample_summary = qxy.assign_samples(adata) Adds adata.obs["Sample"] and warns on overlapping sample annotations.
qxy.add_metadata Add sample-level metadata from CSV, TSV, or DataFrame to adata.obs. qxy.add_metadata(adata, "metadata.tsv", sample_col="ImageID") Adds metadata columns to every cell by sample.
qxy.qc Create QC tables and an HTML QC report. qc = qxy.qc(adata, sample_col="ImageID") QC TSV tables and qc_report.html.
qxy.assign_tma_cores Assign cells to non-overlapping TMA cores from GeoJSON boundaries. tma = qxy.assign_tma_cores(adata, "tma.geojson") Adds tma_core and TMA metadata columns to adata.obs.
qxy.plot_stacked_bar Plot stacked cell type frequencies per sample or group. qxy.plot_stacked_bar(adata, sample_col="ImageID") PNG, PDF, and frequency tables.
qxy.plot_spatial_celltypes Plot spatial cell type maps with shared scale, centered samples, legend, and scale bar. qxy.plot_spatial_celltypes(adata, sample_col="ImageID") PNG/PDF spatial plots and optional combined plot.
qxy.save Save the current AnnData object to the run H5AD path. qxy.save(adata) Saved quxycell.h5ad.
qxy.load Load a saved QuXYCell H5AD from an H5AD path or output folder. adata = qxy.load("qxy_outputs_YYMMDD-HHMM") AnnData.
qxy.load_latest Load the latest timestamped QuXYCell run in a folder. adata = qxy.load_latest() AnnData.
qxy.workflow Convenience wrapper for run, metadata, ignore removal, celltyping, QC, plots, and save. adata = qxy.workflow(qupath_project) Completed AnnData workflow.

Common Notebook Workflow

import quxycell as qxy

qupath_project = "/path/to/qupath_project"

adata = qxy.run(qupath_project)
qxy.remove_ignore(adata)

prompt = qxy.celltype_prompt(
    adata,
    context="Add biological/project context here."
)

# Save YAML returned by an LLM into the run celltype folder, then:
summary = qxy.celltype(adata)

qxy.add_metadata(
    adata,
    "sample_metadata.tsv",
    sample_col="ImageID",
)

qxy.qc(adata, sample_col="ImageID")

qxy.plot_spatial_celltypes(
    adata,
    sample_col="ImageID",
    combined=True,
    max_cols=2,
)

qxy.plot_stacked_bar(
    adata,
    sample_col="ImageID",
    group_col="group",
)

qxy.save(adata)

Metadata Commands

Goal Command Notes
Add metadata matched on QuPath image names qxy.add_metadata(adata, "metadata.tsv") Default sample_col="Image".
Add metadata matched on short sample names qxy.add_metadata(adata, "metadata.tsv", sample_col="ImageID") ImageID must already exist in adata.obs.
Metadata file uses a different key column qxy.add_metadata(adata, "metadata.tsv", sample_col="ImageID", metadata_sample_col="sample_id") Use when metadata has sample_id but AnnData has ImageID.
Add only selected metadata columns qxy.add_metadata(adata, "metadata.tsv", columns=["group", "mouse_id"]) Prevents importing unused metadata columns.
Overwrite existing metadata columns qxy.add_metadata(adata, "metadata.tsv", overwrite=True) Use deliberately.

TMA Commands

Goal Command Notes
Assign TMA cores using default QuPath image matching qxy.assign_tma_cores(adata, "geojson/tma_cores.geojson") Default sample_col="Image".
Assign TMA cores using short sample IDs qxy.assign_tma_cores(adata, "geojson/tma_cores/", sample_col="ImageID") GeoJSON filename stems should match ImageID values.
Use a custom output column qxy.assign_tma_cores(adata, "tma.geojson", core_col="core_id") Stores core assignment in adata.obs["core_id"].
Change metadata prefix qxy.assign_tma_cores(adata, "tma.geojson", metadata_prefix="core_") Core metadata columns become core_....
TMA matching rule: TMA GeoJSON files are matched to adata.obs[sample_col] using the GeoJSON filename stem. With the default sample_col="Image", this matches QuPath image names. For example, slideA.ome.geojson matches slideA.ome.tiff. TMA core overlap is not allowed.

Plotting Commands

Goal Command Output
Stacked bar by sample qxy.plot_stacked_bar(adata, sample_col="ImageID") PNG, PDF, and CSV frequency tables.
Stacked bar by group qxy.plot_stacked_bar(adata, sample_col="ImageID", group_col="group") Group-level mean frequencies.
Limit to selected celltypes qxy.plot_stacked_bar(adata, celltypes=["T_cell", "Macrophage"]) Only selected categories plotted.
Spatial plot by sample qxy.plot_spatial_celltypes(adata, sample_col="ImageID") One spatial figure per sample.
Combined spatial panel qxy.plot_spatial_celltypes(adata, sample_col="ImageID", combined=True, max_cols=2) Individual plots plus combined PNG/PDF.
Selected samples qxy.plot_spatial_celltypes(adata, sample_col="ImageID", samples=["beat-2", "beat-5"]) Restricts plots to listed samples.
Smaller points qxy.plot_spatial_celltypes(adata, point_size=0.3, underlay_size=0.1) Better for dense cell maps.
Palette control qxy.plot_spatial_celltypes(adata, palette="tab20") Uses a matplotlib palette.

Image Name Mapping

image_name_map = {
    "long_original_image_name_1.ome.tiff": "sample-1",
    "long_original_image_name_2.ome.tiff": "sample-2",
}

image = adata.obs["Image"].astype(str)
adata.obs["ImageID"] = image.map(image_name_map).fillna(image)

QuXYCell Overview

A Python bridge from manually exported QuPath single-cell data to AnnData.

QuXYCell turns a QuPath project into an analysis-ready AnnData spatial object. It reads cell level measurement tables, object classifier JSON files, and GeoJSON annotation polygons, then combines cell measurements, marker positivity calls, spatial coordinates, region labels, and sample metadata into an .h5ad file for downstream analysis in Scanpy, Squidpy, pandas, and custom Python workflows.

Overview

QuXYCell reads a QuPath project folder containing exported measurements, classifier JSON files, and GeoJSON annotations. It extracts marker measurements, applies QuPath classifier thresholds, assigns annotation labels from spatial boundaries, and stores the result as an AnnData .h5ad object for downstream spatial single-cell analysis.

The goal is to make QuPath outputs immediately usable with tools like Scanpy, Squidpy, pandas, and custom Python workflows without relying on Jupyter notebooks as the pipeline itself.

Current Workflow

import quxycell as qxy

qupath_project = "/path/to/qupath_export"

report = qxy.check(qupath_project)

adata = qxy.run(qupath_project)

If no output folder is supplied, qxy.check(...) writes reports to:

./qxy_outputs_YYMMDD-HHMM

The saved .h5ad from qxy.run(...) is written by default to:

./qxy_outputs_YYMMDD-HHMM/run/h5ad/quxycell.h5ad

Inputs

QuXYCell currently expects a manually exported QuPath project/export folder containing:

measurements.csv or measurements.tsv
classifiers/object_classifiers/*.json
GeoJSON annotation files

The measurement table must contain standard QuPath columns:

Image
Object ID
Centroid X µm
Centroid Y µm

Outputs

qxy_outputs_YYMMDD-HHMM/
  check_report.txt
  check_report.json
  tables/
    measurement_files.csv
    classifier_report.csv
    geojson_report.csv
    validation_messages.csv
  run/
    h5ad/
      quxycell.h5ad
    tables/
      cells_obs.csv
      markers_var.csv
      annotation_conflicts.csv

Technical Overview

QuXYCell has two main user-facing functions:

qxy.check(project_dir)
qxy.run(project_dir)

check()

Performs preflight inspection and validation. It discovers measurement tables, classifier JSONs, and GeoJSON files; checks required measurement columns; parses classifier JSONs; reports unsupported composite classifiers; and writes a validation report.

run()

Performs the conversion. It loads the measurement table, selects marker columns referenced by simple QuPath classifier JSONs, builds AnnData, applies marker positivity calls, maps GeoJSON annotation polygons to cells, and writes the final .h5ad.

AnnData Layout

adata.X contains the raw marker measurement matrix. There is one column per successfully parsed simple classifier JSON.

adata.obs contains per-cell metadata and computed annotations:

Image
Object ID
Centroid X µm
Centroid Y µm
quxy_source_file
quxy_source_row
quxy_cell_id
<marker>_pos
annotation__<label>

Example marker positivity columns:

CD3_pos
CD4_pos
CD8_pos
PD1_pos
GZMB_pos

Example annotation columns:

annotation__Ignore
annotation__Region
annotation__Unclassified

adata.var contains marker/classifier metadata:

marker_name
classifier_name
source_measurement_column
threshold
classifier_json

adata.obsm["spatial"] contains cell centroid coordinates from QuPath:

Centroid X µm
Centroid Y µm

adata.uns["quxycell"] contains run metadata, check status, number of classifiers, number of GeoJSON files, and annotation conflict counts.

Classifier Handling

In v1, QuXYCell imports one marker column for each simple QuPath classifier JSON of the form:

measurement column >= threshold

Composite classifiers are detected and skipped with warnings. They are reported in:

tables/classifier_report.csv

Cell Type Logic Prompt

QuXYCell can generate a copy-pasteable prompt for an external LLM to draft a first-pass cell type logic YAML from the markers present in a loaded AnnData object:

prompt = qxy.celltype_prompt(adata)

By default, the prompt is printed below the notebook cell and saved to:

qxy_outputs_YYMMDD-HHMM/celltype/celltype_prompt_YYMMDD_HHMMSS.txt

The generated YAML can be saved as:

qxy_outputs_YYMMDD-HHMM/celltype/celltype_logic.yaml

and applied with:

qxy.celltype(adata, "qxy_outputs_YYMMDD-HHMM/celltype/celltype_logic.yaml")

Annotation Handling

GeoJSON annotation polygons are mapped to cells by testing each cell centroid against annotation boundaries. Each annotation class/name becomes a boolean column in adata.obs.

If the same cell is hit by overlapping polygons with the same annotation label, QuXYCell reports that in:

run/tables/annotation_conflicts.csv

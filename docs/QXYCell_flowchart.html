QXYCell technical workflow

A staged QuPath-to-AnnData workflow with explicit checkpoints, a mutually exclusive threshold branch, and targeted rerun dependencies.

Forward workflow

Stages 1–5 update the active H5AD and refresh both tables/cells_obs.csv and tables/markers_var.csv. Optional Stage 2b refreshes the filtered H5AD and cells_obs.csv; preflight and Stage 6 create reports or plots without changing the active checkpoint.

  1. PREP
    Required

    Prepare QuPath project

    Export the measurements and spatial assets that define the run inputs.

    Verify image calibration and prepare measurement, annotation, cell, and threshold assets before import.

  2. ✓
    Optional

    Optional preflight — qxy.check(...)

    Validate the QuPath project before creating an analysis checkpoint.

    Writes a timestamped check report without applying thresholds, generating a prompt, or assigning cell types.

  3. 1
    Required

    Stage 1 — qxy.import_cells(...)

    Create the base AnnData checkpoint from the QuPath measurement table.

    Initializes the active output folder and the measurements stage.

  4. 2
    Required

    Stage 2 — qxy.add_annotations(...)

    Refresh GeoJSON-derived annotations, samples, and cell polygons.

    Use the verified square-pixel value with pixel_size_um to scale GeoJSON coordinates.

  5. 2b
    Optional

    Optional Stage 2b — qxy.remove_cells(..., remove_cells="ignore")

    Remove cells inside Ignore-labelled tissue or staining-artifact polygons.

    This changes the shared checkpoint; rebuild stages 1–2 before rerunning it when Ignore polygons change.

  6. 3
    Choose one source

    Stage 3 — Apply marker thresholds

    Choose exactly one threshold source:

    3A · Classifier JSON

    Apply QuPath classifier thresholds and save thresholds/classifier_thresholds.tsv.

    3B · Reviewed table

    Apply thresholds from one explicitly named table only.

    3A and 3B are alternatives; run one, not both.

  7. 4
    Required

    Stage 4 — qxy.celltype_prompt(...)

    Create the project-specific prompt for drafting cell-type logic.

    Writes prompt context for review while preserving an existing expert-edited YAML.

  8. ★
    Expert review

    Expert review — review and save celltype_logic.yaml

    Validate and correct the proposed biological logic before cell typing.

    Save the reviewed YAML at the configured path used by Stage 5.

  9. 5
    Required

    Stage 5 — qxy.celltype(...)

    Assign cell types from the expert-reviewed YAML rules.

    Updates cell-type, feature, derived-feature, count, and rule-summary outputs.

  10. 6
    Optional

    Optional Stage 6 — qxy.plot_spatial(...)

    Create spatial plots of the assigned cell types.

    Use show=False for scripted runs; output PNGs can be grouped by Sample or Image.

  11. →
    Downstream

    Downstream analysis — Scanpy, Squidpy, pandas, or custom Python

    Use the staged AnnData checkpoint and exported tables for analysis.

    Continue in the scientific Python ecosystem without reimporting unchanged QuPath measurements.

Rerun dependencies

Annotation/cell GeoJSON changed→Stage 2, optional Stage 2b, then Stages 3–5
Ignore polygons changed→rebuild Stages 1–2, then Stage 2b and Stages 3–5
Thresholds changed→selected Stage 3 path, then Stages 4–5
Prompt context changed→Stage 4; preserve expert-edited YAML
Cell-type YAML changed→Stage 5 and optional Stage 6
